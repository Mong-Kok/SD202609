# SD202609 — 邪馬台国・卑弥呼時代の皆既日食「可能性マップ」

『Software Design』誌 連載「万能IT技術研究所」第52回(2026年9月号)のサンプルコードです。

NASA公開のBessel要素から古代日食を自前計算し、ΔT(地球自転の累積遅れ)の
不確実性をモンテカルロ軌道アンサンブルとして流し込んで、
「可視皆既/深食を経験した確率」の日本地図を作るコード一式。

## 依存関係

```bash
pip install numpy matplotlib global-land-mask
```

(global-land-maskは海岸線描画用。なければ地図は点のみで描画される)

## ファイル構成

| ファイル | 内容 |
|---|---|
| `bessel_engine.py` | Bessel要素エンジン。局地食分・可視皆既判定・ΔT閾値探索。`python3 bessel_engine.py` で検算一式を実行 |
| `deltat_ensemble.py` | ΔT(t)モンテカルロ軌道アンサンブル(潮汐ドリフト+ランダムウォーク揺らぎ)と中国史料制約の重み |
| `run_analysis.py` | 解析ランナー。図1〜4とCSVを生成。`python3 run_analysis.py` |
| `figures/` | 生成図版(実行時に生成) |
| `output/site_probabilities.csv` | 候補日食×シナリオ×代表地点の確率 |
| `output/totality_delta_t_windows.csv` | 各地点が可視皆既になるΔT区間 |

## 設計の要点

1. **ΔT=経度シフトの等価性**: 観測点の時角は H = μ + λ − 0.00417807·ΔT。
   ΔTはこの1箇所にのみ現れるため、ΔT変更は観測点の経度シフトと厳密に等価。
   確率地図は「基準ΔTの可視皆既マスク × ΔT分布(経度換算)の畳み込み」で
   高速に計算できる(直接モンテカルロとの照合済み、最大誤差0.017)。
2. **幾何学的最大と可視最大の分離**: 247年の日食は日本では日没際。
   幾何学的最大が地平線下の地点は、日没時刻(大気差込み真高度−0.57°)へ
   Newton法でクリップして食分を評価する。
3. **検算**: NASA公表の最大食地点・時刻、国立天文台報2012系の
   大宰府・飛鳥の食分値、皆既閾値ΔT(飛鳥≈9656s、大宰府≈11963s)を再現。

## 注意(研究利用時)

- Bessel要素はNASAの採用幾何(太陽VSOP87/月ELP-2000/82)に基づく。
  ΔT値は必ず「どの暦表・月理論とペアか」を明記すること。
- 日付はユリウス暦。時刻はTT/UTを区別。JSTは存在しない時代。
- 月縁地形・地形地平線・天候は含まない。
- ΔT揺らぎのアンサンブルは、各年代の周辺分布の分散を
  NASA σ式(×膨張係数)に合わせた経験的モデルであり、
  物理的なコア・マントル結合のシミュレーションではない。
